# Skills del Proyecto

Catálogo de skills modulares configuradas para el proyecto **Gestor de Facturas de El Eco**.

---

## Skills Disponibles

| Skill | Ubicación | Propósito |
| :--- | :--- | :--- |
| **`invoice-system-extractor`** | [invoice-system-extractor/SKILL.md](./invoice-system-extractor/SKILL.md) | Guía operativa para diagnosticar, modificar o añadir reglas de extracción de facturas con Gemini (Sistema 1, Sistema 2 y futuros sistemas). |
| **`sqlite-wasm-migrations`** | [sqlite-wasm-migrations/SKILL.md](./sqlite-wasm-migrations/SKILL.md) | Procedimiento para evolucionar el esquema de base de datos local SQLite y su persistencia en `localStorage` sin corromper datos de usuarios. |
| **`excel-export-formatter`** | [excel-export-formatter/SKILL.md](./excel-export-formatter/SKILL.md) | Instrucciones para mantener y extender la generación de planillas Excel (.xlsx) con SheetJS, formatos de celda y columnas. |
| **`electron-desktop-packager`** | [electron-desktop-packager/SKILL.md](./electron-desktop-packager/SKILL.md) | Procedimiento para compilar, resolver rutas y empaquetar ejecutables de escritorio (.exe) preservando workers y SQLite WASM. |
